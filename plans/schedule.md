# 嘟嘟鸟思维课堂 — 网站建设计划

## 项目概览

- **网站名称**：嘟嘟鸟思维课堂
- **技术栈**：Docusaurus v3 + TypeScript
- **内容领域**：数学、物理、计算机科学、思维训练游戏
- **角色设定**：理论物理学博士、自由职业者

---

## 第一阶段：项目初始化与基础设施（第 1–3 天）

### 第 1 天：项目脚手架搭建
- [ ] 使用 `npx create-docusaurus@latest` 初始化项目，选择 TypeScript 模板
- [ ] 配置 `docusaurus.config.ts`：网站名称、标语、导航栏基础结构
- [ ] 安装必要插件：`remark-math` + `rehype-katex`（数学公式渲染）、`prism-react-renderer`（代码高亮）
- [ ] 初始化 Git 仓库，创建 `.gitignore`
- [ ] 本地启动确认项目可运行

### 第 2 天：主题与布局定制
- [ ] 自定义首页 Hero 区域：标语、简介、CTA 按钮
- [ ] 配置导航栏：数学 | 物理 | 计算机 | 思维游戏 | 关于
- [ ] 配置页脚：版权信息、社交媒体链接
- [ ] 选择/微调配色方案（学术风格，暖色调为主）
- [ ] 配置中文字体与排版

### 第 3 天：文档结构与侧边栏
- [ ] 设计文档目录结构（见下方内容架构）
- [ ] 配置侧边栏 `sidebars.ts`，按领域分组
- [ ] 编写首页欢迎内容（中英双语简介）
- [ ] 创建"关于"页面：介绍网站理念与作者背景
- [ ] 配置 SEO 基础元数据

## 每日工作约定

| 时间块 | 工作内容 |
|--------|---------|
| 上午 (2h) | 内容撰写与研究 |
| 下午 (2h) | 前端开发与组件实现 |
| 傍晚 (1h) | 代码审查、内容校对、进度更新 |

- **每周日**：回顾本周进度，调整下周计划，写一篇周报。
- **每个模块结束时**：整体检查该模块的完整性和一致性。
