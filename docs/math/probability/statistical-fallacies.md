# 统计思维陷阱

## 1. 辛普森悖论

当数据被分组时，每一组都呈现一种趋势，但合并后趋势完全反转。

:::note 经典案例
1973 年，加州大学伯克利分校的研究生录取数据：
- 总体上，男性录取率高于女性（性别歧视？）
- 但按系别分组后，女性在大多数系的录取率高于男性

原因是女性更倾向于申请录取率低的竞争激烈的系。
:::

## 2. 幸存者偏差

只看到成功的案例而忽略失败的案例。

> 二战期间，统计学家瓦尔德建议在**没有弹孔**的部位加固飞机——因为被击中那些部位而没能返航的飞机都被忽略了。

## 3. 回归谬误

将自然的均值回归误解为因果关系。

如果一次异常好的表现后往往跟着一次平庸的表现，这不意味着"自满导致退步"，而是概率分布的必然。

## 4. 检察官谬误

混淆 $P(\text{证据} \mid \text{无辜})$ 与 $P(\text{无辜} \mid \text{证据})$。
