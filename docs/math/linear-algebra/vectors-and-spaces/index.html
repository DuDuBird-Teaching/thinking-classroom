向量与空间

向量不只是"箭头"​

向量是线性代数的核心对象。在物理中，它是力和速度；在计算机中，它是数据和特征。

  • 几何视角：有方向和大小的箭头
  • 代数视角：有序数对 (x,y)(x, y)(x,y) 或 (x1,x2,…,xn)(x_1, x_2, \dots, x_n)(x1​,x2​,…,xn​)
  • 抽象视角：满足加法和数乘的任意元素

线性组合与张成空间​

给定两个向量 v⃗\vec{v}v 和 w⃗\vec{w}w，它们的线性组合是：

av⃗+bw⃗,(a,b∈R)a\vec{v} + b\vec{w}, \quad (a, b \in \mathbb{R})av+bw,(a,b∈R)

所有可能的线性组合形成张成空间（span）。两个不共线的向量张成整个平面。

基与维度​

  • 基：一组能生成整个空间的最少向量
  • 维度：基中向量的个数

平面是 2 维的，我们生活的物理空间是 3 维的，但数学中可以研究任意维度！
