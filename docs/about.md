# 关于本站

## 我们的理念

**嘟嘟鸟思维课堂**是一个致力于传播数学、物理与计算机科学思维的在线学习平台。

我们相信：

- **思维可以训练**：就像肌肉一样，正确的练习能让思维变得更强大
- **理解比记忆更重要**：记住公式不是目的，理解其背后的思想才是
- **好奇心是最好的老师**：好的问题比好的答案更有价值

## 关于作者

我是一名理论物理学的博士，也是一名自由职业者。在学习与教学的旅程中，我发现最有效的学习方式不是被动地接收信息，而是**主动地探索、推理和实践**。

这个网站汇集了我认为最有价值的思维工具和最具启发性的知识。
