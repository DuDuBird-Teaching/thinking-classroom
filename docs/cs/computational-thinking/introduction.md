# 计算思维导论

## 计算思维的四个支柱

### 1. 分解

将复杂问题分解为更小的、可管理的子问题。

> 你想写一个国际象棋 AI？先分解为：棋盘表示 → 合法走法生成 → 局面评估 → 搜索最佳走法。

### 2. 模式识别

在不同问题中发现共同的底层结构。

> 最短路径导航、网络路由、社交网络分析——都是图论中的"最短路径问题"。

### 3. 抽象

忽略无关细节，抓住本质结构。

> 在计算机眼中，"学生"是一组属性的集合：（学号，姓名，成绩，…）。真实世界被简化为数据结构。

### 4. 算法设计

用明确的、有限的步骤描述解决方案。
