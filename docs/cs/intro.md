# 计算机科学导论

计算机科学不是关于"怎么用电脑"，而是关于**计算的本质**：

- 什么是可计算的？
- 什么是可高效计算的？
- 如何组织和管理信息？

## 本模块内容

| 章节 | 主题 | 核心问题 |
|------|------|----------|
| 计算思维 | 抽象与分解 | 如何像计算机科学家一样思考？ |
| 算法思维 | 复杂度与递归 | 什么是好的算法？ |
| 算法可视化 | 排序算法 | 如何直观地看到算法的运行？ |
| AI 与机器学习 | 神经网络与 LLM | 机器如何"学习"？ |
| 编程思维 | Git 与函数式编程 | 如何构建可靠的软件系统？ |

> 计算机科学不是关于计算机，就像天文学不是关于望远镜。 —— 艾兹格·迪杰斯特拉
