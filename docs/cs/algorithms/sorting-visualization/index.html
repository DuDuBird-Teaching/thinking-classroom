排序算法可视化

为什么需要排序？​

排序是计算机科学中最基础的操作之一。数据库索引、搜索优化、数据可视化——都依赖排序。

三种经典排序​

冒泡排序​

相邻元素两两比较，大的"浮"到右边。

  • 时间复杂度：O(n2)O(n^2)O(n2)
  • 空间复杂度：O(1)O(1)O(1)（原地排序）
  • 特点：简单但慢
[5, 3, 8, 1] → [3, 5, 1, 8] → [3, 1, 5, 8] → [1, 3, 5, 8]

快速排序​

选一个"基准"（pivot），小的放左边，大的放右边，递归处理两边。

  • 平均时间复杂度：O(nlog⁡n)O(n \log n)O(nlogn)
  • 最坏时间复杂度：O(n2)O(n^2)O(n2)
  • 特点：实际中最快的通用排序

归并排序​

将数组一分两半，分别排序，然后合并两个有序数组。

  • 时间复杂度：O(nlog⁡n)O(n \log n)O(nlogn)（稳定的）
  • 空间复杂度：O(n)O(n)O(n)
  • 特点：稳定排序，适合链表
