# 复杂度与 Big-O

## 为什么需要复杂度？

同一个问题可以有多种算法解决。如何比较哪种更好？

运行时间依赖于硬件——我们需要一种**与机器无关**的度量方式。

## Big-O 记号

$O(f(n))$ 描述算法在最坏情况下，当输入规模 $n \to \infty$ 时，运行时间的**增长速率**（阶）。

| Big-O | 名称 | 示例 |
|-------|------|------|
| $O(1)$ | 常数时间 | 数组按索引访问 |
| $O(\log n)$ | 对数时间 | 二分查找 |
| $O(n)$ | 线性时间 | 遍历数组 |
| $O(n \log n)$ | 线性对数 | 归并排序 |
| $O(n^2)$ | 平方时间 | 冒泡排序 |
| $O(2^n)$ | 指数时间 | 旅行商问题（暴力法） |

## 直观理解

对于 $n = 10^6$：
- $O(n)$ 约 $10^6$ 次操作（毫秒级）
- $O(n^2)$ 约 $10^{12}$ 次操作（小时级）
- $O(2^n)$ 约 $2^{10^6}$ 次操作（宇宙死了也算不完）
