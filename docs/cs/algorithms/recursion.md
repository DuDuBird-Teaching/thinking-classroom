# 递归思维

## 什么是递归？

**递归**是指一个函数调用自身来解决问题。核心要素：

1. **基准情形**（base case）：直接解决，不再递归
2. **递归情形**（recursive case）：将问题缩小，递归调用自身

## 经典例子：阶乘

$$
n! = \begin{cases}
1 & n = 0 \text{（基准情形）} \\
n \times (n-1)! & n > 0 \text{（递归情形）}
\end{cases}
$$

```python
def factorial(n: int) -> int:
    if n == 0:          # 基准情形
        return 1
    return n * factorial(n - 1)  # 递归情形
```

## 汉诺塔

有三根柱子和 $n$ 个大小不同的圆盘。目标是将所有圆盘从 A 柱移到 C 柱，规则：
- 每次只移动最上面的一个圆盘
- 大盘不能放在小盘上面

:::tip 递归策略
1. 将 $n-1$ 个盘从 A 移到 B（递归）
2. 将最大的盘从 A 移到 C
3. 将 $n-1$ 个盘从 B 移到 C（递归）
:::

最优步数：$T(n) = 2^n - 1$。当 $n=64$ 时，即使用每秒移动一次的速度，也需要约 5850 亿年。
