# 神经网络直觉

## 一个神经元

生物神经元接收信号，当积累的信号超过阈值时，发放一个脉冲。

**人工神经元**模仿这个过程：

$$
y = f(w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b)
$$

- $x_i$：输入信号
- $w_i$：权重（学习的目标）
- $b$：偏置
- $f$：激活函数（如 ReLU）

## 为什么"深"？

单层网络能表示的函数有限。堆叠多层神经元后，网络可以学习**层次化的特征**：

| 层 | 学习的内容（以图像为例） |
|----|------------------------|
| 第 1 层 | 边缘、颜色 |
| 第 2 层 | 纹理、简单形状 |
| 第 3 层 | 部件（眼睛、轮子） |
| 第 4+ 层 | 完整物体（人脸、汽车） |

## 训练 = 调整权重

神经网络通过**反向传播**算法来学习：
1. 前向传播：输入 → 计算输出
2. 计算误差（损失函数）
3. 反向传播：将误差从输出层传回输入层，计算梯度
4. 更新权重：小步调整，减小误差

重复数十万次，网络逐渐学会任务。
