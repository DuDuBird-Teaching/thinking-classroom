守恒律之美

三大守恒律​

能量守恒​

能量不会凭空产生或消失，只会从一种形式转化为另一种形式。

E总=Ek+Ep=常数E_{\text{总}} = E_k + E_p = \text{常数}E总​=Ek​+Ep​=常数

动量守恒​

在没有外力作用的系统中，总动量保持不变。

p⃗=mv⃗,∑p⃗前=∑p⃗后\vec{p} = m\vec{v}, \quad \sum \vec{p}_{\text{前}} = \sum \vec{p}_{\text{后}}p​=mv,∑p​前​=∑p​后​

角动量守恒​

旋转中的"惯性"——滑冰运动员收拢手臂时，转速加快。

诺特定理（预告）​

每一种守恒律都对应着物理定律的一种对称性：

守恒量对称性
能量时间平移对称性
动量空间平移对称性
角动量空间旋转对称性

这是理论物理中最优美的定理之一——我们将在"物理思维方法"模块中深入学习。
