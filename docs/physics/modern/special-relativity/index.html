两个基本假设​

  1. 相对性原理：在所有惯性参考系中，物理定律的形式相同
  2. 光速不变原理：真空中光速 ccc 在所有惯性参考系中都是相同的

时间的相对性​

设想一辆以接近光速飞驰的火车。车厢天花板上的灯向下发射一束光，被地板上的镜子反射回来。

  • 车上的乘客看到光垂直上下，路程很短
  • 站台上的观察者看到光走了一条斜线（因为火车在移动），路程更长

由于光速在两者看来相同，所以站台上的人看到的事件用了更多时间——运动的时钟走得慢！

Δt=Δt01−v2c2=γΔt0\Delta t = \frac{\Delta t_0}{\sqrt{1 - \frac{v^2}{c^2}}} = \gamma \Delta t_0Δt=1−c2v2​​Δt0​​=γΔt0​

其中 γ=1/1−v2/c2\gamma = 1/\sqrt{1 - v^2/c^2}γ=1/1−v2/c2​ 是洛伦兹因子。
