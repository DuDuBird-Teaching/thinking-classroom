# 量子力学思维

## 经典物理的三次冲击

| 实验/现象 | 冲击的信念 |
|-----------|-----------|
| 黑体辐射 | 能量是连续的 |
| 光电效应 | 光是纯粹的波 |
| 双缝实验 | 物体有确定的位置 |

## 叠加原理

量子系统的状态可以是多个"经典可能性"的**线性叠加**：

$$
|\psi\rangle = \alpha|0\rangle + \beta|1\rangle
$$

其中 $|\alpha|^2 + |\beta|^2 = 1$。

:::warning 常见误解
叠加不是"系统同时处于两个状态，但我们不知道是哪一个"。叠加态是客观的，不是无知的产物。在测量之前，电子真的不"在一个确定的位置"。
:::

## 测量问题

测量迫使系统从叠加态"坍缩"到一个确定的结果。为什么测量与其他物理过程不同？这是量子力学最深刻的未解之谜之一。

## 薛定谔的猫

> 把一只猫关在盒子里，盒中有一个由放射性衰变触发的毒气装置。一小时后，原子有 50% 概率衰变。在打开盒子之前，猫是死是活？

薛定谔设计这个思想实验是为了指出量子叠加概念的荒谬性——当你把叠加从微观扩展到宏观时，会得到"半死半活"的猫。

:::tip 现代观点
大多数物理学家现在认为，宏观物体（如猫）与环境相互作用后会迅速**退相干**——实际上不可能维持叠加态。薛定谔的猫永远不会被观察到在死活的叠加中。
:::
