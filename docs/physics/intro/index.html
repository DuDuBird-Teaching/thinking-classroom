物理思维导论

物理学是关于"世界如何运转"的学问。但更重要的是，它代表了一种独特的思维方式：

  • 第一性原理思考：将复杂现象分解为最基本的定律
  • 数量级估算：在不精确计算的情况下判断什么是重要的
  • 对称性与守恒律：寻找不变量是物理学的核心策略
