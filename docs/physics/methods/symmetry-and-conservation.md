# 对称性与守恒律

## 诺特定理

1918 年，德国数学家艾米·诺特证明了一个定理，将**对称性**与**守恒律**联系起来：

> 每一个连续的对称性都对应一个守恒量。

## 三种基本对称性

### 时间平移对称性 → 能量守恒

如果物理定律不随时间变化（今天和昨天一样），那么系统的总能量守恒。

### 空间平移对称性 → 动量守恒

如果物理定律不随位置变化（这里和那里一样），那么系统的总动量守恒。

### 空间旋转对称性 → 角动量守恒

如果物理定律不随方向变化（朝东和朝北一样），那么系统的总角动量守恒。

## 为什么这"优美"？

它告诉我们，看似不同的守恒律有统一的起源——**对称性**。守恒不是"被设定"的，而是从时空的基本结构自动产生的。
