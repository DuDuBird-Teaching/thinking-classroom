# 思维游戏导论

游戏是人类最自然的学习方式之一。在游戏中，我们：

- 在安全的环境中尝试策略
- 从失败中学到宝贵的经验
- 在乐趣中不知不觉地训练思维

## 游戏分类

| 类别 | 训练的能力 | 代表游戏 |
|------|-----------|----------|
| 逻辑推理 | 演绎推理、条件分析 | 谁在说谎？ |
| 数学游戏 | 数感、模式识别 | 24点、数列推理 |
| 策略博弈 | 前瞻规划、对手建模 | 囚徒困境、Nim |
| 空间思维 | 对称感知、几何直觉 | 对称识别、河内塔 |

## 如何使用这些游戏

- **不要急于看答案**：思考的过程比结果更重要
- **先自己尝试，再读策略分析**：培养"感觉"与理解"原理"同样重要
- **将策略应用到其他地方**：博弈论中的思想也适用于日常生活

> 游戏是思维的体操。——本杰明·富兰克林（化用）
