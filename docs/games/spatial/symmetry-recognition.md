# 对称与空间思维

## 河内塔

河内塔是一个经典的空间思维问题。目标是将所有圆盘从 A 柱移到 C 柱：

- 每次移动一个圆盘
- 大盘不能放在小盘上面

传说某座寺庙里有 64 个金盘，僧侣日夜不停地移动。当所有盘移到 C 柱时，世界将会终结——但即使用最快的速度，也需要约 5850 亿年。

## 对称的类型

### 反射对称（镜像）

图形沿一条线折叠后两边完全重合。

### 旋转对称

图形绕一个点旋转一定角度后与自身重合。

- 圆形：无限阶旋转对称
- 正方形：4 阶旋转对称
- 正六边形：6 阶旋转对称

### 与物理学的联系

- 晶体的对称性决定了物理性质
- 诺特定理将对称性与守恒律联系起来
- 粒子物理中的规范对称性是标准模型的基础
