# 对称图案识别

## 为什么要训练空间思维？

空间思维能力与数学、工程、艺术等领域的学习密切相关。研究表明，空间思维是**可训练的**——通过适当的练习，每个人都能提升。

## 对称的类型

### 反射对称（镜像）

图形沿一条线折叠后两边完全重合。

### 旋转对称

图形绕一个点旋转一定角度后与自身重合。

- 圆形：无限阶旋转对称（转任意角度都重合）
- 正方形：4 阶旋转对称（转 90° 的倍数重合）
- 正六边形：6 阶旋转对称

### 平移对称

图形沿某个方向平移后与自身重合——这就是"图案"的本质。

## 与物理学的联系

- 晶体的对称性决定了它的物理性质
- 诺特定理将对称性与守恒律联系起来
- 粒子物理中的规范对称性是标准模型的基础
