# 谁在说谎？

## 经典问题

在一个岛上有两种人：**诚实者**永远说真话，**说谎者**永远说假话。

你遇到两个岛民 A 和 B。

- A 说："B 是说谎者。"
- B 说："我们两人是不同类型的人。"

**问题：A 和 B 分别是哪种人？**

## 推理过程

我们可以用**分类讨论法**：

### 假设 A 是诚实者

- A 说真话 → "B 是说谎者"为真 → B 是说谎者
- B 说假话 → "我们是不同类型的人"为假 → 两人是**相同**类型
- 但 A 是诚实者、B 是说谎者 → 两人类型**不同** → 矛盾！

### 假设 A 是说谎者

- A 说假话 → "B 是说谎者"为假 → B 是诚实者
- B 说真话 → "我们是不同类型的人"为真 → 两人类型不同
- A 是说谎者、B 是诚实者 → 两人类型确实不同 → 一致！

:::tip 答案
**A 是说谎者，B 是诚实者。**
:::
