谁在说谎？

在一个岛上有两种人：诚实者永远说真话，说谎者永远说假话。

经典问题​

你遇到两个岛民 A 和 B。

  • A 说："B 是说谎者。"
  • B 说："我们两人是不同类型的人。"

问题：A 和 B 分别是哪种人？

推理过程（分类讨论法）​

假设 A 是诚实者：A 说真话 → B 是说谎者 → B 说"我们类型不同"为假 → 两人类型相同 → 矛盾！

假设 A 是说谎者：A 说假话 → B 是诚实者 → B 说"我们类型不同"为真 → 两人类型确实不同 → 一致 ✓

答案：A 是说谎者，B 是诚实者。
