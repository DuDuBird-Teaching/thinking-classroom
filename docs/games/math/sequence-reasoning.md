# 数列推理

## 什么是数列推理？

给定一个数列的前几项，找出隐藏的规律，并预测下一项。这是 IQ 测试和数学竞赛中的常见题型，训练的正是**模式识别**能力。

## 经典例题

**题目 1**：$1, 1, 2, 3, 5, 8, ?$

斐波那契数列，每一项是前两项之和。下一项是 $5 + 8 = 13$。

**题目 2**：$1, 4, 9, 16, 25, ?$

平方数：$1^2, 2^2, 3^2, 4^2, 5^2$，下一项是 $6^2 = 36$。

**题目 3**：$2, 3, 5, 7, 11, ?$

质数序列！下一项是 13。

## 常见规律类型

| 类型 | 例子 |
|------|------|
| 等差 | 3, 7, 11, 15, …（公差 4） |
| 等比 | 2, 6, 18, 54, …（公比 3） |
| 平方/立方 | 1, 8, 27, 64, …（$n^3$） |
| 递推 | 每一项与之前几项有关 |
| 交错 | 奇偶位置各有规律 |
