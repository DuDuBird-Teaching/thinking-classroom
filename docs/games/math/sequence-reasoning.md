# 数列推理

## 什么是数列推理？

给定一个数列的前几项，找出隐藏的规律，并预测下一项。这是 IQ 测试和数学竞赛中的常见题型，训练的正是**模式识别**能力。

## 常见规律类型

| 类型 | 例子 |
|------|------|
| 等差 | 3, 7, 11, 15, …（公差 4） |
| 等比 | 2, 6, 18, 54, …（公比 3） |
| 平方/立方 | 1, 8, 27, 64, …（$n^3$） |
| 递推 | 每一项与之前几项有关 |
| 交错 | 奇偶位置各有规律 |
| 外观数列 | "读"出上一项的数字
